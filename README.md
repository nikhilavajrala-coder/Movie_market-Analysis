# Movie_market-Analysis
Power BI dashboard analyzing IMDb movie data, including box-office trends, genres, ratings, votes, runtime, and top-performing movies.# Movie Sales Analysis

## Overview

This project uses Power BI to analyze IMDb movie data from 2006–2016. The analysis explores box-office performance, genres, ratings, votes, runtime, and the performance of movies and directors.

## Objectives

- Analyze box-office revenue trends
- Identify top-performing movies
- Compare movie performance across genres
- Analyze ratings and number of votes
- Explore the relationship between revenue and other movie factors
- Identify top-performing directors

## Tools & Technologies

- Power BI
- DAX
- IMDb Dataset

## Analysis

The dashboard provides insights into:

- Box-office revenue trends
- Genre-wise movie performance
- Movie ratings
- Number of votes
- Movie runtime
- Top movies
- Top directors
- Relationship between revenue and other factors

## Dashboard

The Power BI dashboard provides interactive visualizations that allow users to explore movie performance and compare different aspects of the dataset.
